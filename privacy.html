Политика конфиденциальности

Дата публикации: 30 октября 2026 года

Настоящая политика определяет порядок обработки персональных данных посетителей сайта EXPRESSKEY.

1. Какие данные обрабатываются

Имя, номер телефона, марка и год автомобиля, а также описание задачи, которые посетитель добровольно указывает в форме заявки.

2. Для чего нужны данные

Данные используются только для обратной связи по заявке, предварительной оценки работ и согласования времени обращения.

3. Передача данных

После отправки формы сообщение направляется в Telegram для связи с мастером. Данные не продаются и не передаются третьим лицам для рекламы.

4. Согласие и отзыв

Отправляя форму, посетитель подтверждает согласие на обработку указанных данных. Согласие можно отозвать, обратившись к владельцу сайта по телефону, указанному на сайте.

5. Защита данных

Владелец сайта принимает разумные меры для защиты полученных данных от несанкционированного доступа.
